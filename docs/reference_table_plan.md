# 시즌 기준표를 어떤 '기준점'으로 만들 것인가

작성: 영상처리 파트 · 2026-09-22 · **회의 안건용 초안**

## 1. 문제

기준표를 만들 재료(수집한 연예인 사진)와 실제로 진단할 환경(부스 시연)이 다르다.

| | 수집 사진 | 시연 (부스) |
|---|---|---|
| 흰 종이 | 없음 → **조명 보정 불가** | 있음 → 흰 종이 기준 보정 |
| 조명 | 화보 조명·야외·실내 제각각 | 그날 그 장소의 조명 (고정 가능) |
| 카메라 | 기종·자동 화이트밸런스 제각각 | 우리 노트북 웹캠 하나 |
| 후보정 | 잡티·피부톤 보정, 필터 | 없음 |

→ 수집 사진에서 뽑은 **절대 Lab 값을 그대로 기준표로 쓰면 시연 결과와 어긋난다.**

## 2. 실측 근거 (photo1 = 노란 실내조명 / photo3 = 밝은 조명, 같은 사람)

**보정 방식별로 두 사진의 피부색이 얼마나 일치하는가 (a·b 차이, 작을수록 좋음)**

| 보정 방식 | 피부 a·b 차이 | 메모 |
|---|---|---|
| 보정 없음 | 15.2 | 수집 사진을 그대로 쓰는 경우에 해당 |
| 그레이월드 (사진 전체 평균을 회색으로) | 8.1 | 흰 종이 없이 쓸 수 있는 대체 보정 |
| 눈 흰자를 흰색 기준으로 | 10.9 | 시도했으나 실패 — 흰자가 어둡고 붉어서 색이 과하게 틀어짐 |
| **흰 종이 기준 (우리 방식)** | **3.4** | 시연 경로 |

**흰 종이 보정값과 그레이월드 보정값의 차이(오프셋)가 사진마다 다름**

| | L 차이 | a 차이 | b 차이 |
|---|---|---|---|
| photo1 | +9.1 | +4.7 | **−3.6** |
| photo3 | +8.8 | +4.3 | **+7.9** |

L·a 오프셋은 비슷하지만 **b(노랑-파랑) 오프셋은 부호까지 다르다.** b는 웜/쿨 판정의 핵심 축이다.
→ "수집 사진 값에 일정한 보정값을 더해 시연 환경으로 옮기기"는 **불가능**하다고 봐야 한다.

## 3. 그래서 이렇게 하자 (제안)

**A. 기준표의 '진짜 기준점'은 우리 환경에서 찍은 앵커 사진으로 잡는다.**
- 시연과 똑같은 조건(같은 노트북 웹캠, 같은 조명, 흰 종이 포함)에서 20~30명 촬영.
- 팀원·지인으로 충분하다. 시즌별로 최소 몇 명씩은 있어야 한다.
- 기준표의 숫자는 **이 사진들에서 뽑은 값**으로 정한다.

**B. 수집한 연예인 사진은 '절대값'이 아니라 '경향'을 보는 데 쓴다.**
- 용도 1: 시즌 사이에 **어떤 값이 실제로 갈리는지** 확인 (b가 갈리나? a가 갈리나? 명도 대비가 갈리나?)
- 용도 2: 경계 케이스 사례 수집 (55:40 같은 애매한 사람들)
- 용도 3: 라벨링 연습 — 우리 팀이 시즌을 얼마나 일관되게 판단하는지 확인
- 처리 방법: `python tools/batch_extract.py <폴더>` (그레이월드 보정이 기본으로 적용됨)
- **하지 말 것**: 연예인 사진 평균 Lab 을 그대로 기준표 숫자로 넣기

**C. 판정에 쓰는 값은 조명·노출에 덜 흔들리는 것 위주로.**
- 실측상 보정 후에도 **밝기(L)는 계속 흔들린다** (photo1 74.4 / photo3 63.2).
- 피부-머리 밝기차도 49.1 vs 30.3 으로 흔들린다 → 명도 기반 축(브라이트/딥 등)은 신중히.
- 반면 보정 후 **a·b 는 잘 맞는다** (피부 3.4, 머리 2.5). 웜/쿨 판정을 a·b 중심으로 잡는 게 안전하다.
- 눈동자는 영역이 작아 오차가 크다 (photo1 홍채 픽셀 약 500개) → 가중치를 낮게.

**D. 시연 환경을 고정하고, 시작 전에 점검 루틴을 돌린다.**
- 부스에서 같은 위치·같은 조명·같은 거리로 촬영. 흰 종이는 필수.
- 시연 시작 전 팀원 1명을 찍어서 기준 사진과 결과가 비슷하게 나오는지 확인.
- 결과가 크게 다르면 조명 위치를 바꾸거나, 그날 값으로 한 번 더 맞춘다.

**E. 어긋남은 신뢰도와 퍼센티지로 방어한다.**
- 사진 품질·조명 경고가 있으면 신뢰도를 낮춰 표시.
- 발표에서의 성공 기준은 "정답 적중"이 아니라 **재현성**(같은 사람, 다른 조명 → 비슷한 결과)이다.
  이건 우리가 실제로 보여줄 수 있는 수치다.

## 4. 사진 수집 체크리스트 (예진·민서)

**받을 사진**
- 얼굴이 크고 정면, 눈을 뜬 사진
- 자연광 또는 평범한 실내조명 (일상 스냅·인터뷰 캡처)
- 시즌 라벨의 근거가 있는 인물 (전문 진단 받은 방송/인터뷰 등) → 근거 링크를 같이 기록

**거를 사진**
- 무대조명·컬러조명·역광, 흑백·필터 사진
- 진한 메이크업 화보, 과한 보정
- 옆얼굴, 얼굴이 작게 나온 사진, 흐린 사진 (도구가 경고를 띄워줌)

**정리 방법**
- 폴더를 시즌 이름으로: `data/collected/spring_warm/`, `summer_cool/`, `autumn_warm/`, `winter_cool/`
- 사진과 함께 `수집목록.csv` 에 기록: 파일명 / 인물 / 시즌 라벨 / 라벨 근거 링크 / 조명 메모
- **사진과 CSV 는 GitHub 에 올리지 않는다** (초상권·개인정보). 드라이브로 공유.
- 모이면: `python tools/batch_extract.py data/collected --out outputs/collected.csv`
