# 깃허브 사용법 (팀 공용)

저장소: https://github.com/jisu508/PersonalColor
브랜치는 `main` 하나만 씁니다. PR 없이 각자 main 에 바로 올립니다.

---

## 1. 내가 작업한 걸 올릴 때 (지수)

명령 프롬프트(cmd)에서 폴더로 이동한 뒤, **항상 이 순서**입니다.

```
cd C:\Users\user\Desktop\시보프\personal_color

git pull origin main       ① 남의 작업 먼저 받기
python -m pytest tests -q  ② 테스트 통과 확인 (47 passed)
git status                 ③ 뭐가 바뀌었는지 눈으로 확인
git add .                  ④ 전부 담기
git commit -m "무엇을 왜 바꿨는지"
git push origin main       ⑤ 올리기
```

①을 빼면 ⑤에서 거절당합니다. 순서를 지키는 게 전부입니다.

### 한 번만 해두면 편해지는 것

```
git push -u origin main
```

`-u` 는 main 브랜치의 짝을 정해주는 옵션입니다. 이걸 한 번 하고 나면
그 뒤로는 `git pull`, `git push` 만 쳐도 됩니다 (뒤에 `origin main` 안 붙여도 됨).

### 커밋 메시지 쓰는 법

무엇을 바꿨는지 한 줄이면 됩니다. 나중에 "언제 뭐가 바뀌었지" 찾을 때 씁니다.

```
git commit -m "웜쿨 기준선 45도로 재보정, 촬영 조건 게이트 원복"
git commit -m "웹 연결 규격 정리, 종이 탐지 안정화"
```

`-m` 뒤 따옴표를 빼먹으면 편집기가 열려서 당황하게 됩니다. 꼭 큰따옴표로 감싸세요.

## 2. 팀원이 최신 코드를 받을 때

### 처음 한 번 (아직 폴더가 없을 때)

```
cd C:\Users\본인이름\Desktop          원하는 위치로
git clone https://github.com/jisu508/PersonalColor.git
cd PersonalColor
python -m pip install -r requirements.txt
python -m pytest tests -q             47 passed 나오면 준비 끝
```

### 그 뒤로 매번 (이미 폴더가 있을 때)

```
cd C:\Users\본인이름\Desktop\PersonalColor
git pull origin main
```

이거 한 줄이면 끝입니다. 코드를 고치지 않고 받기만 한다면 평생 이 줄만 쓰면 됩니다.

### 팀원도 코드를 고쳐서 올릴 거라면

지수와 똑같이 `pull → add → commit → push` 순서입니다.
**작업 시작 전에 반드시 `git pull origin main` 부터** 하세요. 이걸 빼면 충돌이 납니다.

## 3. 자주 만나는 상황

### push 가 거절됨 (`rejected`)

```
! [rejected]  main -> main (fetch first)
```

원인은 항상 하나입니다 — 내가 작업하는 동안 남이 먼저 올렸습니다.

```
git pull origin main
git push origin main
```

### pull 하니까 파란 화면이 뜸 (Vim)

병합 메시지를 쓰라는 화면입니다. 그냥 **`ZZ`** (대문자 Z 두 번) 누르면 저장되고 나갑니다.
다시 안 보고 싶으면 한 번만:

```
git config --global core.editor notepad
```

### `index.lock: File exists`

```
fatal: Unable to create '.../.git/index.lock': File exists.
```

앞선 git 명령이 비정상 종료돼 잠금 파일이 남은 것입니다. 지우면 됩니다.

```
del .git\index.lock
```

### `There is no tracking information for the current branch`

`git pull` 만 쳤을 때 나옵니다. `git pull origin main` 으로 치거나,
`git push -u origin main` 을 한 번 해두면 없어집니다.

### 잘못 담았을 때 (커밋 전)

```
git restore --staged 파일이름     담은 것만 취소 (내용은 그대로)
git restore 파일이름              내가 고친 내용까지 되돌리기 (주의: 복구 불가)
```

## 4. 올리면 안 되는 것

`.gitignore` 에 걸려 있어서 자동으로 빠지지만, `git status` 에서 한 번씩 확인해주세요.

| 대상 | 이유 |
|---|---|
| `data/samples/`, `data/collected/`, `data/captures/` | **사람 얼굴 사진 — 개인정보** |
| `*.webp` | 수집한 연예인 사진 |
| `outputs/`, `__pycache__/`, `.venv/` | 자동 생성물 |

사진은 깃 대신 카톡으로 주고받고, 각자 같은 폴더 이름에 넣습니다.
`git status` 에 사진 파일 이름이 보이면 **커밋하지 말고** 먼저 알려주세요.
